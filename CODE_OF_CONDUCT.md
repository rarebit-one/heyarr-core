# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be decent. Assume good faith, argue about the design rather than the
person, and accept that "no" is a legitimate answer to a feature request.

Report unacceptable behaviour by opening a
[private security advisory](https://github.com/rarebit-one/heyarr-core/security/advisories/new)
or contacting the maintainers directly. Reports will be handled confidentially.
