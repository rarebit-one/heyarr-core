# Specification

[`heyarr-spec.md`](heyarr-spec.md) is the technical specification, kept in-repo
so it is versioned with the code that implements it.

It describes the intended system, not the current one. Where the two disagree,
the specification is the intent and the gap is a bug or an unstarted milestone —
except where an [ADR](../adr/) explicitly records a decision to depart from it.
Section numbers are stable and referenced from code comments, ADRs and issues.
